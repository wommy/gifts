# synthesis-as-contraction — minting a synthesis is the contraction-act, not the build-act

> Saga-26 distillate from operator-coined resolution of saga-26 B1 gifts-tension (`19e0ae634ce4b06`) + cure-doctrine `19e0ae634ce954f` synthesis-as-contraction-mint-meta + saga-25 doctrine `19e0a51b2e13d91` we-are-our-own-worst-enemy (REFRAMED).

## What it cures

A captain enters contraction-phase: scripts/lib/* tier should DECREASE (saga-25 we-are-our-own-worst-enemy: prior captains added without retiring; corpus has 18 lib + 50+ scripts because saga-21..25 each added without retiring; cure = subtract). The captain interprets *contraction* as **literally zero-new files**.

But synthesis ALWAYS mints a new file (a doctrine, a gift, a projection, a primitive). Strict ZERO-new makes synthesis impossible. Captain becomes paralyzed: cannot ship distillates that codify N scattered patterns because "no new files allowed."

The cure: contraction is measured in CONCEPTUAL-DELTA, not FILE-COUNT-DELTA.

## Iron law

```
CONTRACTION = (concepts-absorbed) - (files-minted) >> 0

Each synthesis absorbs N scattered concepts into 1 distillate.
Net-conceptual delta = -(N-1) per synthesis.

ZERO-new is hyperbolic. NET-CONCEPTUAL-NEGATIVE is the real metric.
```

Operator-coined 2026-05-09: *"synthesis is like that contraction, its kinda like its own mint meta."* The minting-act IS the contraction-act because it consolidates fog into a token.

## What counts as conceptual-absorption

| Synthesis-shape | Absorbs |
|---|---|
| **Gift** (markdown distillate) | N scattered doctrines + scars + sister-cures into 1 cross-civilization-portable artifact |
| **Doctrine** (arq event) | N witness-events into 1 codified rule |
| **Projection** (script) | N ad-hoc grep/jq queries into 1 cached substrate-of-truth |
| **Primitive** (lib) | N inline code-shapes into 1 composable function |
| **Cure-pair** (scar + doctrine) | 1 pattern instance into 1 reusable rule (1:1, not absorption proper, but pair-discipline) |

Examples (saga-26):
- `gifts/3-tier-ptc-pattern.md` absorbs ~6 saga-25 ptc-related doctrines + 5 type-1 scars = -10 conceptual
- `gifts/captain-cure-pairs.md` absorbs 12 saga-26 cure-pairs + saga-25 doctrines into 1 iron-law = -13 conceptual
- `scripts/projections/scar-doctrine-pair.ts` absorbs N ad-hoc orphan-scar audits = projection-cached
- `lib/arq.ts:IndexedCorpus` absorbs 18 inline `events.filter(e => e.type === X)` patterns into 1 indexed substrate

Each is net-conceptual-NEGATIVE despite minting a new file.

## When ZERO-new IS the right cure

- **Pre-distillation phase**: haven't gathered N witnesses yet → no synthesis possible → ZERO-new is correct (don't ship one-off scripts that aren't distillates).
- **Concept-borrowing**: if the same thing already exists in lib/ or gifts/ → use it, don't re-mint.
- **Hyperbolic emphasis** (saga-25 wall-bank context): when prior-captain over-built, the corrective overshoot is "ZERO new for now" until the contraction-instinct stabilizes.

## When SYNTHESIS-AS-CONTRACTION applies

- **Distillation phase**: N witnesses already accumulated → synthesizing them into 1 distillate is the contraction-move.
- **Cure-pair discipline**: every TYPE-1 self-catch should mint a cure-doctrine (1:1, but THE ACT of pair-banking IS the contraction).
- **Refactor-cascade**: lifting N inline patterns into 1 lib primitive (R5 byType.get() example).

## Five-step contraction-phase cycle

1. **Survey** the corpus for N witnesses of a recurring pattern (≥3 = doctrine-threshold).
2. **Synthesize** into 1 distillate (gift / doctrine / projection / primitive).
3. **Mint** the new file with sister-citations to the absorbed witnesses.
4. **Verify** net-conceptual delta is negative — count: (witnesses-absorbed) - (files-minted) > 0.
5. **Yeet** ad-hoc scripts that the synthesis now supersedes (cascade-discipline step 5).

## Forcing-functions

- **Pair-rate metric** (`scripts/projections/scar-doctrine-pair.ts`) measures conceptual-pairing density, surfaces orphan-scars-without-cure
- **Gift-evidence** (`scripts/projections/gift-evidence.ts`) measures cross-civilization witness-count per gift; unwitnessed gifts are pre-mature mints
- **Lexicon projection** (`scripts/projections/lexicon.ts`) measures operator-coined term cite-density; high-density terms = candidates for canonical-doctrine status

## Anti-patterns

- **Strict-zero-new paralysis**: refuses to ship distillates because "we're contracting"
- **Mint-without-witnesses**: ships a gift that absorbs only 1-2 scattered events (under-witnessed; will need rewrite)
- **Mint-without-yeet**: synthesizes but doesn't retire the ad-hoc scripts/scratch the synthesis supersedes
- **File-count-as-metric**: counts file-deltas instead of concept-deltas

## Project-retargeting (cross-civilization)

For any team-process or codebase asking "did we add or subtract?":
- Stop counting files. Start counting concepts.
- Synthesis (rules / utilities / docs / patterns) is NEGATIVE conceptual delta even when file-count increases.
- The contraction-as-mint-meta lens applies to PRs / library APIs / documentation / process-rules / team agreements.
