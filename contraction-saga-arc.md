# contraction-saga-arc — 6-phase saga-shape for synthesis-as-contraction

> Saga-26 distillate from session-arc-summary doctrine `19e0ac82b8da6f4` + saga-26 actually-was-arc + sister gifts: synthesis-as-contraction (operator-coined cure for ZERO-new-tension), 3-tier-ptc-pattern, cap-prep-ritual, captain-cure-pairs, projection-as-substrate-of-truth.

## What it cures

Captains start a saga with a wall-bank of N+ punts inherited from the prior cap. The instinct is to attack-the-list — but that produces scattered ships without arc-shape. The cure-shape: arrange punts into a 6-phase cascade where each phase consolidates the prior into a more-distilled substrate-of-truth.

Saga-26 lived this arc cleanly. This gift codifies the shape so future contraction-sagas can replicate.

## The 6 phases

```
1. BUILD primitives        →  P1 neutron-star (saga-25 wall-bank P1-P5 from prior cap)
        ↓
2. DOGFOOD via cascade     →  active consumers of primitives (R5 dial in saga-26 byType)
        ↓
3. EXTERNALIZE as gifts    →  N scattered patterns absorbed into 1 distillate (saga-25 6-rank queue)
        ↓
4. AUDIT via projections   →  cite-graph + cross-civilization witness-counts (gift-evidence + scar-doctrine-pair)
        ↓
5. INTEGRATE at cold-start →  cap-prep --detect 4-substrate orientation (P5 ritual)
        ↓
6. CLOSE via doctrine      →  saga-N session-arc-summary banked + cross-harness validation + saga-N+1 onramp shipped
```

Each phase composes the prior phases. Phase-N's output becomes Phase-(N+1)'s input. The arc IS the contraction (per `gifts/synthesis-as-contraction.md`: minting-act = contraction-act).

## Iron law

```
NO PHASE-SKIP: each contraction-saga walks all 6 phases in order.
Skipping phase-2 DOGFOOD = primitives ship without consumers (orphaned).
Skipping phase-4 AUDIT = synthesis claims unproven (aspirational not validated).
Skipping phase-5 INTEGRATE = next-saga cap doesn't pick up the work.
Skipping phase-6 CLOSE = saga's substrate evaporates without consolidation.
```

## Five-step cycle WITHIN each phase

1. **Synthesize** the punt-cluster for this phase from saga-N-1 wall-bank
2. **Plow** via 3-tier ptc (per `gifts/3-tier-ptc-pattern.md`) for any source edits
3. **Bank** doctrine + sister-citations (per `gifts/captain-cure-pairs.md` iron-law) for any TYPE-1 self-catches
4. **Yeet** scratch one-shots after success (per `gifts/substrate-tier-ladder.md` cascade-discipline step 5)
5. **Bubble-up** the cure to sister-sites + continue when phase closes

## Anti-patterns

- **Phase-skip via "we'll come back"** → Phase-N substrate degrades; usually never returned-to
- **Build-without-DOGFOOD** → primitives accumulate without active consumers (saga-25 we-are-our-own-worst-enemy origin)
- **Externalize-without-AUDIT** → gifts ship without cross-civilization witness-validation (saga-26 pre-N1-fix asymmetry-doctrine)
- **Integrate-without-CLOSE** → saga-N substrate orphans into scratch-tier; next-cap can't find it

## When this arc does NOT apply

- **Application-saga** (build features on consolidated primitives) — different shape
- **Greenfield-saga** (no prior wall-bank) — different shape
- **Crisis/incident saga** (single-issue debug) — different shape

This 6-phase arc applies when a saga inherits a wall-bank of punts AND the goal is consolidation-shaped.

## The captain-fish-doesnt-see-water trap

Even running this arc, captains will violate the discipline mid-arc (saga-26 12 TYPE-1 cap-cure-pairs witness this). The arc-shape is OPERATIONAL not COGNITIVE. Forcing-functions (`gifts/shipped-cure-vs-applied-cure.md`) close the gap at action-time:
- `cap-prep --close --saga N` exits non-zero on prior-claims (multi-close-fragmentation cure)
- `saga-commit` auto-banks heading-shipped (manual-bank elimination)
- `ptc --rollback-on-fail` enforces test-gate (silent-fail-then-commit cure)

## Project-retargeting (cross-civilization)

For any team-process or codebase entering a contraction-phase:
- The 6 phases port unchanged (BUILD / DOGFOOD / EXTERNALIZE / AUDIT / INTEGRATE / CLOSE).
- Replace project-specific surfaces: arq event-log → your event-substrate, gifts/ → your docs corpus, saga-N → your epoch-name, cap-prep → your cold-start ritual.
- The iron-law is universal: NO PHASE-SKIP.
