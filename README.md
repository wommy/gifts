## Origin

> Saga-21 BOOM 2026-05-06: an agent burned ~150k tokens fighting plan-mode-instruction-block before realizing operator-grant + `Bash(bun:*)` settings already made writes tractable. The cure was — name the layered constraint, replicate doctrine across 8 substrates, externalize distillations as gifts.

The pattern: build doctrines that *survive* compaction by living in multiple substrates, then *share* the distillations because the same friction is everyone's friction.
